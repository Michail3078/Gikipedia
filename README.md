# Gikipedia — Энциклопедия видеоигр

Gikipedia — это открытая энциклопедия видеоигр, созданная для игроков, разработчиков и энтузиастов. Платформа позволяет создавать, редактировать и делиться статьями о видеоиграх, общаться с другими пользователями и находить единомышленников.

## 🚀 Основные возможности

### 📝 Статьи
- **Создание статей** с названием, описанием, тегами и обложкой
- **Множественные теги** — добавляйте несколько тегов через запятую
- **Поиск по тегам** — кликайте на теги для поиска похожих статей
- **Редактирование и удаление** — авторы и модераторы могут редактировать контент
- **Красивое отображение** — обложки, описания, теги в виде кликабельных бейджей

### 👤 Пользователи и профили
- **Регистрация и авторизация** с ролями (user, moderator, admin)
- **Настраиваемые профили** с аватаркой и описанием
- **Система друзей** — отправка заявок, принятие/отклонение
- **Личные сообщения** — чат между друзьями

### 🔍 Поиск
- **Умный поиск** по статьям и пользователям
- **Поиск по тегам** — кликайте на теги для автоматического поиска
- **Фильтрация результатов** — разделение на статьи и пользователей

### 🛠️ Администрирование
- **Панель администратора** для модераторов и админов
- **Система жалоб** — пользователи могут жаловаться на контент
- **Управление пользователями** — просмотр и управление пользователями

### 💬 Социальные функции
- **Уведомления** — система оповещений о новых сообщениях и заявках в друзья
- **Чат** — общение между друзьями в реальном времени
- **Лента друзей** — просмотр активности друзей

## 🛠️ Технологический стек

- **Backend**: Flask 3.1.0 (Python)
- **Database**: SQLite3 с миграциями
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Templates**: Jinja2
- **Styling**: Кастомный CSS с поддержкой темной/светлой темы

## 📦 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone <repository-url>
cd Gikipedia-Artem
```

### 2. Создание виртуального окружения
```bash
python -m venv .venv
```

### 3. Активация виртуального окружения
- **Windows**:
  ```bash
  .venv\Scripts\activate
  ```
- **macOS/Linux**:
  ```bash
  source .venv/bin/activate
  ```

### 4. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 5. Инициализация базы данных
База данных инициализируется автоматически при первом запуске приложения.

### 6. Запуск приложения
```bash
python -m flask run
```

Приложение будет доступно по адресу: [http://localhost:5000](http://localhost:5000)

Приложение поддерживает переключение между темной и светлой темами. Кнопка переключения находится в хедере.

### Адаптивный дизайн
Интерфейс адаптируется под разные размеры экранов:

### Быстрый доступ
- **Кнопка "Создать статью"** в хедере для авторизованных пользователей
- **Поиск** в реальном времени
- **Уведомления** с быстрым доступом к действиям

## 📱 Основные страницы

### Главная страница (`/`)
- Лента последних статей
- Быстрый доступ к поиску и созданию статей
- Приветственный блок

- Предпросмотр обложки

- Поиск по статьям и пользователям
- Фильтрация результатов
- Поиск по тегам (клик на тег)

### Чат (`/chat`)
- Список диалогов
- Личные сообщения
- Уведомления о новых сообщениях

### Админ-панель (`/admin`)
- Управление пользователями
- Просмотр жалоб
- Модерация контента

## 🏷️ Работа с тегами

### Добавление тегов
При создании или редактировании статьи вы можете добавить несколько тегов:
1. Введите тег в поле "Теги" и нажмите **Enter** или **запятую**
2. Тег появится в виде цветного бейджа
3. Для удаления тега нажмите на крестик (×) на бейдже
4. Теги сохраняются через запятую в базе данных

### Поиск по тегам
- **Клик на тег** в любой статье автоматически выполняет поиск по этому тегу
- **Поисковая система** ищет по тегам, названиям и содержанию статей
- **Множественные теги** позволяют лучше классифицировать контент

### Примеры тегов
- `RPG` — ролевые игры
- `FPS` — шутеры от первого лица
- `Инди-игры` — независимые проекты
- `Мультиплеер` — игры с сетевым режимом
- `Сюжетные` — игры с глубоким сюжетом
- `Открытый мир` — игры с открытым миром
